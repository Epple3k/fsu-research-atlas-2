## Trust interpretation

Answer these before writing the case-study result:

1. Did evidence visibility increase source-checking behavior?
2. Did explanation accuracy improve?
3. Did trust change without an accuracy change?
4. Did anyone trust the control more because it looked simpler?
5. Did participants understand what the time comparison meant?
6. Did participants distinguish a measured observation from an interpretation?

A higher trust score is not automatically a positive result. The stronger result is trust supported by verification and accurate explanation.

## Case-study result draft

Use this structure after the numbers are real:

> I tested the claim-to-evidence workflow with [N] participants using a counterbalanced comparison. In the evidence-first condition, [n/N] participants [observable behavior], compared with [n/N] in the claim-only condition. Median explanation accuracy changed from [x] to [y], while median trust changed from [x] to [y]. The most consequential failure was [specific failure], which led me to [specific interface change]. In a formative retest with [N] participants, [outcome].

Delete any metric that does not illuminate the design decision. Include an honest limitation:

> This was a small convenience sample intended to guide product iteration, not establish a generalizable effect.
